# 간단 메모장

## 실행

https://jademindesk-svg.github.io/simple-memo/ 에서 메모장 계정으로 로그인합니다. 메모를 저장한 뒤 상단 **저장된 기록**에서 본인 기록을 최신순으로 확인합니다. **다시 불러오기**로 다른 기기에서 저장한 기록을 조회하며, 20개를 넘으면 **기록 더 보기**를 누릅니다.

## 검증

- 저장 기록 영역과 로그인 안내를 실제 배포 화면에서 확인했습니다.
- 목록 조회, 페이지 추가 조회, 일반 텍스트 출력, 조회 오류 표시, 로그아웃 중 진행 중인 응답 차단 테스트 통과.
- 실제 DB에서 본인 메모 조회·추가·삭제 허용 및 다른 사용자 메모 조회·추가·삭제 차단을 트랜잭션으로 검증한 후 롤백했습니다.
- 실제 웹 로그인 이후 목록 표시·저장·삭제는 인증 완료 후 확인이 필요합니다. 이메일 확인 해제 설정은 미완료입니다.
