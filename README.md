# 간단 메모장

## 실행

- 사용자: https://jademindesk-svg.github.io/simple-memo/
- 관리자: https://jademindesk-svg.github.io/simple-memo/admin.html
- 관리자 계정은 기존 메모장 가입 계정입니다. Supabase 대시보드 로그인과 구분됩니다.
- 사용자는 본인 메모만 조회·저장·삭제합니다. 관리자는 회원 이메일·표시 이름·가입일·최근 로그인·인증 상태를 조회하고, 이메일·표시 이름을 수정합니다.
- 회원 삭제는 대상 이메일을 입력해 확인하며 회원과 해당 회원의 메모를 영구 삭제합니다. 관리자 계정 삭제와 관리자 로그인 이메일 변경은 차단합니다. 비밀번호는 조회·수정하지 않습니다.

## 검증

- 사용자/관리자 별도 페이지 배포 및 관리자 로그인 화면 확인.
- 실제 관리자 API에서 비로그인·잘못된 토큰 요청 401 확인.
- 실제 DB에서 관리자 판정, 일반 회원의 관리자 권한 부재 및 관리자 목록 접근 차단 검증(롤백).
- 모의 API/화면 테스트: 회원 목록과 페이지 이동, 수정 허용 필드, 수정 충돌, 관리자 계정 보호, 이메일 확인 후 삭제, XSS 방지, 세션 변경 시 회원 정보 제거 통과.
- 기존 회원 정보 수정·삭제는 실행하지 않았습니다. 실제 웹 로그인은 인증정보 오류로 관리자 목록·수정·삭제 최종 확인이 남아 있습니다. 기존 이메일 확인 해제 설정도 미완료입니다.
