# 간단 메모장

## 실행

https://jademindesk-svg.github.io/simple-memo/ 에서 이메일·비밀번호로 가입 또는 로그인하고 메모를 저장합니다.

## 검증

- 하늘색 홈페이지 디자인 배포, 첫 화면 및 소개·로그인 영역 이동 확인. 반응형 레이아웃 적용.
- HTML ID 및 JavaScript 문법 검사 통과. 데스크톱 가로 넘침 없음, 입력 글자 16px 확인.
- Supabase memos 테이블 및 본인 메모 SELECT·INSERT·DELETE RLS 정책 확인, 보안 검사 통과.
- 미완료: 이메일 확인 해제 설정 및 실제 가입·자동 로그인·메모 저장/삭제·새로고침 유지·재로그인 검증.
